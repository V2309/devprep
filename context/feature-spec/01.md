Use Zustand instead of React Context.

Create stores:

store/
├── auth-store.ts
├── question-store.ts
├── category-store.ts
├── profile-store.ts
└── ui-store.ts

Move all state currently stored in App component into Zustand stores:
- questions
- profile
- isLoggedIn
- categories
- searchQuery
- toast

Replace Context Provider usage with Zustand hooks.

Do not create AppProvider or Context Provider unless absolutely necessary.
